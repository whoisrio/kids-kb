

## 纯图片

走ocr，先使用rapid ocr(依赖pymupdf)进行解析； 

meta要支持定制，默认包含:
- 源文档名称
- 页码
- 章节(如果能读取到)
- 创建时间
- 更新时间


知识类文档，
- 书名(文件名不一定是书名)
- 科目(数学、语文、英语)
- 年级
- 题源
- 题号
- 题型(判断，选择，填空)
- 分类(代数、几何)
- 特殊标签(强基 ? 冲奥 ? )
- 难度 ? 
- 图片路径 []



如果是传ocr，页中的图片怎么给裁出来 ? 
先读取结构 -> llm 分析哪些属于题干，题干后面的图片位置大概率就是题目相关的图片 -> 通过 pp-structure / unlimited ocr 拿图片坐标位置；

# 题目视图设计

## 目标

页详情右侧提供题目视图。
视图按题目卡片聚合结构化结果，而不是平铺 OCR 块或独立条目。

## 数据语义

`exercise` 与 `example` 是题目主条目。
`answer` 是解析条目，优先通过 `paired_item_id` 归入对应题目卡片。
没有配对题目的解析保留为未配对解析卡片，避免内容丢失。

## API

`GET /api/review/pages/:id` 返回 `questions`。
每个题目卡片包含题干 Markdown、题目复核状态、关联块和裁图。
配对解析包含解析 Markdown、解析复核状态和当前页内的解析关联块。

## UI

工具栏将「条目视图」改为「题目视图」。
题目卡片分区呈现题干与解析，并继续使用 Markdown/KaTeX 渲染。
页图上的条目标签默认只出现在当前选中块上，避免同一题目的多个来源块重复遮挡页图。
